= SnaKt usage example

Small test project exercising the SnaKt formal verification plugin
(`org.jetbrains.kotlin.formver`). Used to smoke-test that the locally
published plugin works end-to-end and to demonstrate `@AlwaysVerify`,
`preconditions`, `postconditions`, `verify`, and `kotlin.contracts`.

== Git workflow

- main-direct: commit and push straight to `main`. No branches, no PRs.
